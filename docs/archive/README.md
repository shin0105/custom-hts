## 한국어

이 폴더에는 개발 과정에서 작성된 **과거 문서**가 그대로 보관되어 있습니다. 대부분 AI 코딩 에이전트(GitHub Copilot, Claude Code)가 작업 중에 남긴 구현 보고서, 테스트 보고서, 코드 리뷰 기록, 기획 문서입니다.

> ⚠️ **현재 코드와 다를 수 있습니다.** 이 문서들은 작성 당시의 상태를 기록한 것이며 이후 갱신되지 않습니다. 예를 들어 IP 화이트리스트, GitHub Actions 워크플로, Supabase 기반 토큰 저장소 등은 이미 제거되었거나 다른 방식으로 바뀌었습니다. 최신 정보는 [`docs/README.md`](../README.md)와 루트 [`README.md`](../../README.md)를 참고하세요.

번역하지 않고 원문(대부분 영어) 그대로 둡니다.

| 경로 | 내용 |
|------|------|
| `implementations/` | 기능별 구현 기록 (OpenDART, yfinance, KIS, 캔들 차트, DB 스키마 등) |
| `reports/` | 테스트 실행 결과 및 분석 보고서 |
| `reviews/` | 코드 리뷰 결과 기록 |
| `PROJECT_SUMMARY.md`, `PR_SUMMARY.md` | 초기 프로젝트 요약 및 PR 요약 |
| `GITHUB_SETUP.md` | 삭제된 GitHub Actions 워크플로 설정 안내 |
| `UI_UX_ENHANCEMENT_PLAN.md` | 국내 주식/채권/파생 화면 UI/UX 감사 및 개선 계획 |

## English

This folder keeps **historical documents** produced during development, unchanged. Most are implementation reports, test reports, code-review notes and planning documents written by AI coding agents (GitHub Copilot, Claude Code) while they worked.

> ⚠️ **They may not match the current code.** Each document records the state of the project when it was written and is not maintained. For example, the IP whitelist, the GitHub Actions workflows and the Supabase-backed token store have since been removed or replaced. For up-to-date information see [`docs/README.md`](../README.md) and the root [`README.md`](../../README.md).

They are kept in their original language (mostly English) and are not translated.

| Path | Contents |
|------|----------|
| `implementations/` | Per-feature implementation notes (OpenDART, yfinance, KIS, candle charts, DB schema, …) |
| `reports/` | Test runs and analysis reports |
| `reviews/` | Code-review findings |
| `PROJECT_SUMMARY.md`, `PR_SUMMARY.md` | Early project and PR summaries |
| `GITHUB_SETUP.md` | Setup notes for GitHub Actions workflows that no longer exist |
| `UI_UX_ENHANCEMENT_PLAN.md` | UI/UX audit and improvement plan for the KR stock / bond / derivatives pages |
