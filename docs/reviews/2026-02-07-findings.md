## Finding 1
**[P3] Time filter applies to non-intraday data**  
**File:** `<repo-root>/frontend/src/pages/USMarketPage.tsx:55`

**Problem**  
`startTime` filtering runs for all intervals, including daily/weekly/monthly. This can silently drop candles.

**Fix**  
Only apply the time filter for intraday intervals, or when the data includes timestamps with time.

**Suggested approach**
1. Define a helper like `const isIntraday = ['1m','5m','15m','30m','60m'].includes(interval);`
2. Gate the time filter block with `if (startTime && isIntraday) { ... }`
3. Alternatively, detect `c.date` strings containing time and only filter those.

## Finding 2

## Finding 3
**[P1] SSL verification disabled for downloads**  
**File:** `<repo-root>/backend/src/integrations/stock_master.py:89`

**Problem**  
SSL verification is disabled globally for downloads, which enables MITM attacks.

**Fix**  
Remove the override and keep SSL verification enabled. If needed, supply a CA bundle explicitly.

**Suggested approach**
1. Delete `ssl._create_default_https_context = ssl._create_unverified_context`
2. Use default HTTPS verification.
3. Add retry logic or allow a custom CA path as configuration if required.

## Finding 4
**[P1] Batch insert parameters parsed as query**  
**File:** `<repo-root>/backend/src/api/financial_statements.py:393`

**Problem**  
FastAPI treats `symbols`, `year`, `quarters` as query parameters for POST. JSON body input is ignored.

**Fix**  
Define a Pydantic request model and accept it as a POST body.

**Suggested approach**
1. Create:
   ```python
   class BatchInsertRequest(BaseModel):
       symbols: List[str]
       year: int
       quarters: Optional[List[int]] = None
   ```
2. Update endpoints to `async def batch_insert_korean_statements(request: BatchInsertRequest)`

## Finding 5
**[P2] Async methods wrap sync I/O**  
**File:** `<repo-root>/backend/src/integrations/supabase_client.py:37`

**Problem**  
`async` methods directly call a sync Supabase client, which can block the event loop.

**Fix**  
Make them sync, and call in a threadpool, or switch to an async Supabase client.

**Suggested approach**
1. Convert methods to sync (`def`).
2. In FastAPI, call them via `run_in_threadpool`.
3. Alternatively, replace with an async Supabase client and keep `async`.

## Finding 6
**[P2] Network call during client init**  
**File:** `<repo-root>/backend/src/integrations/opendart.py:30`

**Problem**  
`download_corp_code_list` runs in `__init__`, blocking startup and failing offline.

**Fix**  
Make this lazy (on-demand) and cache results with a TTL.

**Suggested approach**
1. Remove the call from `__init__`.
2. On first use, attempt to load cache or download if expired.
3. Store corp codes on disk with a timestamp.
